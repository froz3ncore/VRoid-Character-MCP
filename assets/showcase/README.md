# 效果图来源 / Showcase sources

这些图片是 VRoid Character MCP 开发过程中采集的原生渲染，采集于 **2026-10-19**。它们来自重构前的功能验证记录，不是本次文档更新重新运行的测试，也不是 AI 生成或修饰的效果图。发布文件与所列原图逐字节一致。

| 文件 | 场景与验证范围 |
|---|---|
| `outfit-front.png` | `hem-align-v22` 服装候选，原生换装正面静态预览 |
| `outfit-walk.png` | 同一服装候选，原生行走采集的第 8 帧；不是新导出的动画资产 |
| `makeup-before.png` | `cosmetics-texture-tools-v04` 的眉毛与眼下绘制前基线 |
| `makeup-after.png` | 同一候选绘制后，保存并在新进程重开后的正面近景 |
| `makeup-closed.png` | 同一妆容候选重开后的临时闭眼采集；采集后还原 |
| `nail-index.png` | `nail-visibility-v01` 左手食指，蓝色用于甲面定位测试 |
| `nail-thumb.png` | 同组右手拇指，橙色用于甲面定位测试 |

妆容、美甲和服装来自不同场景，不应理解为已合并的最终角色。坐姿裙摆与部分穿插仍未解决。模型与可编辑素材没有随图发布。

精确来源路径（相对于开发工作区）、SHA-256、采集记录路径见 [SOURCES.json](SOURCES.json)。工作区路径用于追溯，不是仓库内的下载链接。
