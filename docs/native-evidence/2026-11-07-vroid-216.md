Lab preparation, copy startup, attachment preflight and the installation doctor
recognize the following packages. Each 2.16.0 package uses Unity 6000.0.62f1.
The Steam and standalone packages have the same IL2CPP metadata digest,
`089fe945572695f0592e04abaae096c54f7ea74a382a3ce68440e0425b8486b8`.

The serialized Unity PlayerSettings in each 2.16.0 distribution gives
`bundleVersion=2.16.0`. The 836-byte object is identical across channels.
The pixiv-signed Windows installer has SHA-256
`617b59733cbbd6044d1826997157cf5ead8134d7efb8ac393f2614298fe87893`.
The DLLs have byte-identical native code, IL2CPP code, initialized data,
exception tables and relocations. The 22 differing mapped read-only data bytes
belong to PE timestamps and the CodeView PDB identifier. These comparisons
support sharing audited method roles across the two exact 2.16.0 pairs.
The Unity asset bundles differ, including resource path IDs and a serialized
BindableResources byte. Static code identity cannot establish per-channel
rendering or UI behavior. [Official release notes](https://vroid.pixiv.help/hc/en-us/articles/63720616567449--v2-16-0-Save-hair-shapes-Performance-Monitor-Oct-29-2026)
and [official Windows installer](https://download.vroid.com/dist/2cbXSb76Bf/VRoidStudio-v2.16.0-win.exe).

The bridge reads `UnityEngine.Application.get_version()` on the Unity main
thread before installing the copy's mutation hooks or adopting an attachment.
A mismatch stops native dispatch. The original upstream 2.14.0 route can report
its recognized package identity when the managed getter is absent. Session
status and body-reference output include the product version and its source.
The historical `vroid-2.14.0-<area>-v1` parameter-list schema still identifies
that wire format.

On both generations the Length modifier writes the form's Single at offset
`0x10` and supplies command key `ProceduralLength` with `reuseStrands=true`.
HairCount writes the Int32 at offset `0x24`, using `HairCount` and
`reuseStrands=false`. Both use the group parameter set's form at offset
`0x30`. The product binds named native members and managed actions.

A focused comparison preserved the owner, parameters, return type, static flag
and native registration of 51 declarations across 48 named entries. These
include the VRM0/VRM1 export callbacks with `TaskCompletionSource<Boolean>`,
mesh and atlas settings, raster composition and replacement, PNG conversion
and attached completion, material queries, group parameters and commands,
`SaveSync`, frame dispatch, camera projection, face renderer and end-of-frame
readback. The 2.14 four-argument raw bone constructor still has an extra
template-key dictionary on 2.16.0. Uncovered raw bone rows remain read-only.

The focused metadata inventory compared 373 owners per build. Registry async
state-machine fields and awaiters changed, as did a stashed-update lambda and
an unused start-screen error-dialog constructor. The catalog scan observes
the registered update and notification methods. Camera, capture and group
declarations retain the selected bindings. Runtime object ownership, callback
delivery, exported bytes, saved model state and visible results require the
live checks below.

## Real files and remaining acceptance

The source doctor recognized the installed Steam pair and the extracted
standalone pair. Preparation copied and verified all 31 Steam files
(1,272,825,752 bytes). The independent doctor recognized the physical copy and
found its lab lock available. The current Windows account's
`HKCU\SOFTWARE\Classes\vroid.closet` key blocked all three preflights.
No VRoid process was started or attached. The standalone inspection used eight
extracted files and does not establish runnable installation completeness.

To complete native acceptance, prepare a new physical lab in a disposable
Windows test profile where the normal crash guard passes. Run the smoke and
domain cases on that profile and record the outcome per distribution. Pending
gates include bootstrap, F00 creation, parameter read/write and Undo/Redo,
save/reopen, ordinary VRM export, procedural hair, custom refresh, camera and
gallery restoration, menu/exit, and visual review. See the
[native acceptance checklist](../superpowers/native-migration-acceptance.md).
