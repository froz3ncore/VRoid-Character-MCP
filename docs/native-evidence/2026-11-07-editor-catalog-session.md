# Native binding notes for editor capture, catalog scans and session transitions

These notes identify specific bindings in the pixiv-signed standalone VRoid Studio 2.14.0 build, `GameAssembly.dll` SHA-256 `ed65ebbc1e806db635566347a9022b9577f6b3d373db128ea23f0e862e005296`. The [procedural hair evidence](2026-11-07-procedural-hair.md) identifies the installer and matching metadata by hash. Addresses below are PE RVAs (image base `0x180000000`). No application binaries or native method bodies are included.

| Decision | Evidence in this build | What the caller must still establish |
| --- | --- | --- |
| Capture the edit view | `MainViewModel.GlobalBus.EditAvatarCameraPosition` and `PhotoBoothAvatarCameraPosition` are different owners. The projection switch has distinct single-camera and multiple-render-texture branches. In the latter it updates already-instantiated camera groups, not the source template. `EditRootScreen.ViewModel.FaceEditor.GetFaceSMR()` supplies a model-scoped starting point for facial preview. | Match the active edit root, model and camera/group instances and check the effective pose and projection. The presence of the named fields does not identify which view is rendering. |
| Read the application frame | This metadata has no managed `ScreenCapture.CaptureScreenshotAsTexture` binding. Unity's `Awaitable.OnEndOfFrame` and `Texture2D.ReadPixels` are present. Bone selection can modify actual renderer materials through `BuildModifier`; leaving the feature can also remove listeners. | Capture the actual backbuffer at end-of-frame with bounded hook lifetime. For a clean character render, isolate the cloned camera and refuse unproven guide removal; do not clear the user's selection merely to hide an overlay. |
| Certify a registry scan | `CustomItemRegistry.QueueUpdate` (RVA `0x3328540`) forwards to the filesystem observer. `OnUpdate` (`0x332ac70`) receives both observed custom items and observation failures. After rebuilding the registry, its normal path calls `NotifyUpdateFiles` (`0x332ba10`, callsite `0x332b598`). The observer field is an `UnmanagedReferenceMember`, not a direct observer. | Observe the completed callback on the actual registry instance. A quiet queue or unchanged dictionary cannot certify an empty scan; failures or incomplete reads must preserve unknown items. |
| Bind a situation thumbnail to a resource | `RestorationInfo.AssetStorage.AssetCatalog.GetTransferableGroupByName` returns an entry with native ID, resource name and type. It does not supply the current group revision. `ActiveModel.TransferableGroups` exposes actual group headers and direct entries; `TransferableGroupInfo.CreateWithTransferableGroup` (`0x3d7e0a0`) reads the stored `Header.Custom.Revision`. Custom headers also expose `UpdatedSinceLastRevision`. | Bind ID/type/resource before applying; compare stored and active clean versions for the root and its members. A recommendation is not an equipped member, and a catalog ID alone is not an image version. |
| Return to the menu or quit | `GlobalBus.ScreenNavigation.ActiveScreen` distinguishes the concrete start screen from the edit root. The edit-root `BackToModelSelect` action has a native `BackToStartScreen` continuation. On the ordinary quit path the main view model's don't-save callback (`0x30d8350`) forwards to its own `<WantsToQuitHandler>g__Quit\|61_0` continuation (`0x30d7e30`); its state machine has a separate `MoveNext` (`0x30d8440`). XWear has a distinct exit route. | Recheck the active screen and discard authorization before dispatch. A returned callback is only a request: observe the new screen or the selected process actually ending, as appropriate. A missing RPC response cannot certify exit or authorize a forced kill. |

These bindings are evidence about one binary, not evidence of a successful live invocation. Recheck the descriptors and run the [native acceptance cases](../superpowers/native-migration-acceptance.md) before claiming support for an additional build.
